# نظام التنقل الموحد ثنائي المستوى (Main Header + Contextual Breadcrumb Bar)

تطوير وتوحيد نظام التنقل في **Restocash ERP** عبر هيكل ثنائي نظيف ومتكامل على مستوى جميع شاشات البرنامج: **بار رئيسي علوي ثابت دائمًا** لهوية البرنامج والأدوات العامة، و**بار مسار فرعي ذكي أسفله** يظهر فقط عند الدخول إلى أي قسم أو شاشة فرعية لعرض المسار التفاعلي والانتقال السريع دون تكرار أي عنصر من البار الرئيسي.

## القرارات المعتمدة بعد مراجعة المستخدم

> [!IMPORTANT]
> تم تعديل الخطة بالكامل وفق توجيهك الدقيق للفصل بين البار الرئيسي الأساسي وبار المسار الفرعي:

- **1. البار الرئيسي الثابت (Main Sticky Header — يظهر دائمًا في كل الشاشات)**:
  - يثبت في أعلى جميع صفحات البرنامج (لوحة الإدارة، الكاشير POS، الكابتن، الفرن KDS، خزينة الكاشير، وجميع الأقسام).
  - يحتوي حصريًا على: **الشعار واسم البرنامج**، **القائمة المنسدلة السريعة للأقسام**، **محول اللغة**، **محول العملات**، **زر تغيير الوضع الليلي/النهاري**، و**حساب المستخدم وتسجيل الخروج**.
- **2. بار المسار الفرعي (Contextual Breadcrumb Bar — يظهر فقط داخل الأقسام والشاشات الفرعية)**:
  - يقع مباشرة أسفل البار الرئيسي ويكون ثابتًا معه أثناء التمرير.
  - **يختفي تمامًا** في الصفحة الرئيسية للوحة الأقسام (`/admin`)، و**يظهر تلقائيًا** بمجرد الدخول إلى أي قسم رئيسي أو صفحة فرعية أو شاشة تشغيلية.
  - يعرض فقط: **مسار الصفحة التفاعلي (Breadcrumbs)** مع قوائم منسدلة للتبديل السريع بين التبويبات والأقسام، و**زر الرجوع الذكي** للعودة للقسم الأب أو لوحة الأقسام الرئيسية.
  - **منع التكرار نهائيًا**: لا يعيد عرض الشعار أو اسم البرنامج أو اللغة أو العملة أو الوضع الليلي أو بيانات المستخدم.

---

## 1. النظرة العامة والمفهوم الأساسي

- **ماذا يقدم التحديث**: يفصل بوضوح بين **الهوية وأدوات النظام العامة** (في البار الرئيسي الثابت دائمًا) وبين **سياق التصفح والمسار الهرمي** (في البار الفرعي الذي يظهر فقط عند التعمق داخل الأقسام)، مع إزالة الهيدرات المكررة والمختلفة التي كانت موجودة في شاشات الكاشير والكابتن والفرن وخزينة الكاشير.
- **المستخدم المستهدف**: جميع مستخدمي النظام من الإدارة والمحاسبة إلى الكاشير والكابتن والمطبخ.
- **القيمة الأساسية**: ثبات بصري تام للبار الرئيسي في كل مكان، وظهور ذكي لبار المسار عند الحاجة فقط، مع إلغاء أي ازدواجية في أزرار اللغة أو العملة أو الوضع الليلي.

---

## 2. تجربة المستخدم والتصميم البصري

### تدفق الاستخدام الرئيسي (User Flows)
1. **في اللوحة الرئيسية للأقسام (`/admin`)**:
   - يظهر **البار الرئيسي الثابت فقط** في الأعلى (الشعار واسم البرنامج، قائمة الأقسام، اللغة، العملة، الوضع الليلي، المستخدم).
   - لا يظهر بار المسار الفرعي لأن المستخدم في نقطة البداية بالفعل.
2. **عند الدخول إلى أي قسم أو شاشة فرعية (مثل الإدارة المالية، المول، الحديقة، أو شاشة الكاشير POS)**:
   - يبقى **البار الرئيسي** ثابتًا في الأعلى بنفس شكله ومحتوياته دون تغيير.
   - يظهر **بار المسار الفرعي** مباشرة أسفله محتويًا على:
     - مسار هرمي واضح يبدأ من `لوحة الأقسام` ◄ `اسم القسم الحالي` (مع قائمة منسدلة للتبديل السريع لقسم آخر) ◄ `التبويب أو الشاشة الفرعية الحالية` (مع قائمة منسدلة للتبديل الفوري بين التبويبات الشقيقة داخل نفس القسم).
     - **زر رجوع ذكي** في الطرف المقابل يعود خطوة واحدة للقسم الأب أو للرئيسية.
3. **إلغاء التكرار في شاشات التشغيل (`/pos`, `/captain`, `/oven`, `/cashier-treasury`)**:
   - تعتمد هذه الشاشات على نفس البار الرئيسي وبار المسار الفرعي الموحدين، وتُحذف منها أشرطة تغيير اللغة والعملة المكررة، مع الإبقاء فقط على أدوات العمل الخاصة بكل شاشة (مثل حقل بحث الأصناف في الكاشير أو أزرار طباعة الشيفت).

### الهوية البصرية والسمة (Visual Identity & Theme)
- **البار الرئيسي (Main Bar)**: سطح واضح وعصري (`bg-card/95 backdrop-blur-md border-b border-border`) بارتفاع متوازن (`56px`) يضم الهوية في اليمين وأدوات النظام والمستخدم في اليسار.
- **بار المسار الفرعي (Sub-Bar)**: شريط رشيق وأنيق (`bg-muted/40 backdrop-blur-sm border-b border-border/70`) بارتفاع مدمج (`40px`) يركز بصريًا على تسلسل المسار وأسهم الاتجاه وزر الرجوع السريع.
- **دمج زر الوضع الليلي**: نقل زر تبديل الوضع الليلي/النهاري ليصبح جزءًا أصيلًا ومثبتًا داخل البار الرئيسي بجوار اللغة والعملة بدلًا من الزر العائم المنفصل.

## 3. القرارات الهندسية والمفاضلات

- **فصل الهوية والأدوات عن شريط المسار (Two-Tier Sticky Navigation)**:
  - *النهج المختار*: بار رئيسي دائم + بار مسار شرطي يظهر فقط داخل الأقسام.
  - *السبب*: يحقق نظافة الصفحة الرئيسية دون ازدحام، ويوفر داخل الأقسام شريط مسار مخصص بالكامل للتنقل الهرمي والتبويبات الفرعية دون مزاحمة من الشعار أو أزرار الإعدادات.
- **توحيد مصدر بيانات المسار والأقسام**:
  - *النهج المختار*: سجل مركزي واحد للمسارات والأقسام والتبويبات الفرعية يغذي كلًا من القائمة السريعة في البار الرئيسي ومسار التنقل التفاعلي في البار الفرعي.
  - *السبب*: ضمان تطابق المسميات والأيقونات والصلاحيات في جميع أنحاء البرنامج.
- **حماية عناصر محول العملات لأستوديو التطوير**:
  - *النهج المختار*: الإبقاء على `data-studio-preserve="currency-switcher-tools"` حول محول العملة واللغة في البار الرئيسي فقط.
  - *السبب*: الحفاظ على توافق أستوديو التطوير دون تكرار المحول في أكثر من شريط.

## 4. البنية التقنية واستراتيجية الحالة

### مخطط المكونات والتدفق الهيكلي

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│  1. البار الرئيسي الثابت دائمًا (Main Sticky Top Bar — Always Visible)           │
│  [الشعار + اسم البرنامج]  |  [قائمة الأقسام السريعة ▾]  |  [اللغة · العملة · 🌙 · المستخدم] │
├──────────────────────────────────────────────────────────────────────────────────┤
│  2. بار المسار الفرعي (Secondary Breadcrumb Bar — Visible ONLY Inside Sections)  │
│  [لوحة الأقسام] ◄ [اسم القسم الحالي ▾] ◄ [التبويب الفرعي الحالي ▾]     [↩ رجوع] │
└───────────────────┬──────────────────────────────────────────────┬───────────────┘
                    │                                              │
                    ▼                                              ▼
     ┌─────────────────────────────────┐            ┌──────────────────────────────┐
     │  سجل المسارات والتبويبات الموحد │            │   التحكم الذكي في الظهور     │
     │  • الأقسام الرئيسية الـ 8       │            │   • يختفي في: /admin         │
     │  • التبويبات الفرعية لكل قسم    │            │   • يظهر في: كافة الأقسام    │
     │  • شاشات الكاشير والفرن والكابتن│            │     والشاشات الفرعية         │
     └─────────────────────────────────┘            └──────────────────────────────┘
```

### نموذج البيانات وربط الحالة التفاعلية
- **البار الرئيسي (`AppMainNavbar`)**:
  - يعرض الشعار واسم البرنامج (`Restocash ERP`) مع رابط للعودة إلى `/admin`.
  - يضم قائمة منسدلة سريعة للأقسام الرئيسية المصرح بها للمستخدم.
  - يضم أدوات النظام الموحدة: `LanguageSwitcher`، `CurrencySwitcher`، `ThemeToggle` (مدمج داخل البار)، شارة الإصدار، ومعلومات المستخدم مع زر تسجيل الخروج.
- **بار المسار الفرعي (`AppBreadcrumbBar`)**:
  - يفحص المسار الحالي (`pathname` و `search`): إذا كان في `/admin` الرئيسي بدون قسم فرعي يعيد `null` (لا يظهر).
  - عند الدخول لأي قسم أو شاشة فرعية، يعرض المسار التفاعلي:
    - المحطة الأولى: **لوحة الأقسام** (تنقل مباشر للرئيسية).
    - المحطة الثانية: **القسم الرئيسي** (مع قائمة منسدلة للتبديل السريع لأي قسم آخر، أو النقر للعودة لبداية القسم).
    - المحطة الثالثة (إن وجدت): **الصفحة أو التبويب الفرعي** (مع قائمة منسدلة بجميع التبويبات والشاشات الشقيقة داخل نفس القسم للانتقال الفوري بينها).
  - يضم في الجهة اليسرى **زر الرجوع الذكي** الذي يعود للقسم الأب إذا كان في صفحة فرعية، أو للرئيسية إذا كان في المستوى الأول من القسم.
